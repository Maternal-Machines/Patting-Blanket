# Patting-Blanket
Patting Blanket is a prototype from design research project Maternal Machines: Design Speculations about Fantasies of Care, led by Dr Paulina Yurman and funded by Wellcome (2024-2028). Roseanna Eckheart was commission to program and fabricate this prototype, as part of the project’s exploration on patting and other gestures in practices of care.
