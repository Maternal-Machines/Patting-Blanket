# Patting-Blanket
Patting Blanket is a prototype from design research project Maternal Machines: Design Speculations about Fantasies of Care, led by Dr Paulina Yurman and funded by Wellcome (https://wellcome.org/research-funding/funding-portfolio/funded-grants/maternal-machines-design-speculations-about). Roseanna Eckheart was commissioned to fabricate this prototype, as part of the project’s exploration on patting and other gestures in practices of care.
